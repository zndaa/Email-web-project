# 📬 Modern Web Email Client

A full-featured, responsive email web application built with modern web technologies. This client allows users to register, authenticate securely, manage incoming correspondence, compose and send emails to other users, inspect incoming message details, and quickly reply to conversations.

---

## 🌟 Key Features

* **Authentication & User Management:**
  * User sign-up and custom email account creation.
  * Secure sign-in / sign-out flows with persistent session handling.

* **Inbox & Message Management:**
  * Dynamic inbox interface displaying received messages with real-time status.
  * Detailed message inspection view showing sender details, subject, timestamps, and full formatted body content.

* **Send & Reply Capabilities:**
  * Compose and dispatch emails to any registered user within the system.
  * In-app reply functionality pre-filling sender addresses and subject threads.
  * Client-side form validations ensuring valid email recipients and non-empty inputs.

* **Responsive User Interface:**
  * Clean, modular layout designed for both desktop and mobile screens.
  * Interactive navigation transitions between folders, message previews, and modal composers.

---

## 🛠️ Built With

* **Frontend Framework:** Angular
* **Language:** TypeScript, HTML5, SCSS / CSS3
* **State & Asynchronous Data:** RxJS
* **HTTP Client:** Angular HttpClient (REST API Integration)
* **Code Quality & Tooling:** Angular CLI, Prettier, ESLint
